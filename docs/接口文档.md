# 筑梦家 · 前后端接口文档

> 基础地址：`/api`（开发环境由 Vite 代理转发至 `http://localhost:8080`）
> 静态资源：`/files/**`（设计图、生成效果图等，映射到后端 `storage/` 目录）

---

## 1. 通用约定

### 1.1 鉴权

除 `POST /api/auth/register`、`POST /api/auth/login` 外，所有 `/api/**` 接口需在请求头携带 JWT：

```
Authorization: Bearer <token>
```

- Token 由登录/注册接口返回，有效期默认 7 天（`app.jwt.expiration-ms`）。
- 鉴权失败（缺失/无效/过期）返回 `401`，前端自动登出并跳转登录页。

### 1.2 统一响应结构

所有接口返回统一包装：

```json
{
  "code": 200,
  "message": "success",
  "data": { }
}
```

- `code`：业务码，`200` 表示成功；非 200 表示失败。
- `message`：提示信息，失败时含具体原因。
- `data`：业务数据，失败时通常为 `null`。

前端取数逻辑：拦截器在 `code !== 200` 时 `ElMessage.error(message)` 并 `reject`。

### 1.3 错误码

| code | 说明 |
| --- | --- |
| 200 | 成功 |
| 400 | 参数校验失败 / 上传文件过大 |
| 401 | 未登录或 Token 无效（拦截器层与业务层均有） |
| 404 | 业务资源不存在（如生成任务不存在，由 `BusinessException(404, ...)` 抛出） |
| 500 | 服务器内部错误（系统异常） |
| 其他 | `BusinessException` 可携带自定义 code（如智谱额度/Key 错误会在 `errorMessage` 文本中说明） |

### 1.4 上传

文件上传接口使用 `multipart/form-data`，字段名见各接口定义。

## 2. 认证接口 `/api/auth`

### 2.1 注册

`POST /api/auth/register`

**请求体**（JSON）：
```json
{
  "username": "zhangsan",   // 必填，3-32 字符
  "password": "123456",     // 必填，6-64 字符
  "nickname": "张三"        // 可选，默认取 username
}
```

**响应** `data`：`AuthResponse`
```json
{
  "token": "eyJhbGci...",
  "userId": 1,
  "username": "zhangsan",
  "nickname": "张三",
  "avatar": null
}
```

### 2.2 登录

`POST /api/auth/login`

**请求体**（JSON）：
```json
{ "username": "zhangsan", "password": "123456" }
```

**响应** `data`：`AuthResponse`（同注册）

### 2.3 获取当前用户

`GET /api/auth/me` （需鉴权）

**响应** `data`：
```json
{ "id": 1, "username": "zhangsan", "nickname": "张三", "avatar": null }
```

### 2.4 更新个人信息

`PUT /api/auth/me` （需鉴权）

**请求体**（JSON）：
```json
{ "nickname": "新昵称", "avatar": "http://.../a.png" }  // 字段均可选
```

**响应** `data`：`AuthResponse`（同注册）

## 3. 设计项目接口 `/api/projects`

> 所有接口需鉴权；仅能访问**自己**的项目。

### 3.1 创建项目并上传设计图

`POST /api/projects` （`Content-Type: multipart/form-data`）

**表单字段**：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `name` | string | 是 | 项目名称 |
| `description` | string | 否 | 项目描述 |
| `style` | string | 否 | 装修风格 code（见产品文档第 5 节），空/非法回退 `modern-minimalist` |
| `designImage` | file | 是 | 设计图（户型图/CAD/手绘） |

**响应** `data`：`ProjectResponse`
```json
{
  "id": 10,
  "name": "我的三居室",
  "description": "朝阳 120㎡",
  "style": "modern-minimalist",
  "styleLabel": "现代简约",
  "designImageUrl": "http://localhost:8080/files/uploads/xxx.png",
  "createdAt": "2026-07-13T10:00:00",
  "updatedAt": "2026-07-13T10:00:00"
}
```

### 3.2 项目列表

`GET /api/projects` （需鉴权）

**响应** `data`：`ProjectResponse[]`

### 3.3 项目详情

`GET /api/projects/{id}` （需鉴权）

**响应** `data`：`ProjectResponse`

### 3.4 删除项目

`DELETE /api/projects/{id}` （需鉴权）

**响应** `data`：`null`

## 4. 3D 生成接口 `/api`（生成任务）

> 所有接口需鉴权；仅能访问**自己**的任务。

### 4.1 发起生成

`POST /api/projects/{projectId}/generate` （需鉴权）

**说明**：校验项目归属与是否存在设计图 → 创建 `PENDING` 任务落库 → 异步线程池处理（状态流转 `PENDING → PROCESSING → SUCCESS/FAILED`）。调用后立即返回任务信息，前端需轮询状态。

**响应** `data`：`GenerationResponse`
```json
{
  "id": 100,
  "projectId": 10,
  "status": "PENDING",
  "provider": null,
  "modelUrl": null,
  "previewImageUrl": null,
  "panoramaUrl": null,
  "sceneConfig": null,
  "errorMessage": null,
  "createdAt": "2026-07-13T10:01:00",
  "updatedAt": "2026-07-13T10:01:00"
}
```

### 4.2 查询单个生成任务（轮询用）

`GET /api/generations/{id}` （需鉴权）

**响应** `data`：`GenerationResponse`

`status` 取值：`PENDING` / `PROCESSING` / `SUCCESS` / `FAILED`。

### 4.3 项目下的生成记录

`GET /api/projects/{projectId}/generations` （需鉴权）

**响应** `data`：`GenerationResponse[]`（按创建时间倒序）

### 4.4 当前用户所有生成记录

`GET /api/generations` （需鉴权）

**响应** `data`：`GenerationResponse[]`

### 4.5 `GenerationResponse` 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | long | 生成任务 ID |
| `projectId` | long | 所属项目 ID |
| `status` | string | 任务状态（见上） |
| `provider` | string | 实际使用的 AI 提供方（`mock` / `zhipu`） |
| `modelUrl` | string | 3D 模型(glb/gltf) URL，mock 模式为空 |
| `previewImageUrl` | string | 预览缩略图 URL |
| `panoramaUrl` | string | 首张全景/效果图 URL（智谱模式填充） |
| `sceneConfig` | string | 3D 场景描述 JSON 字符串（见第 7 节） |
| `errorMessage` | string | 失败原因（智谱 429/额度/Key 错误均在此体现） |
| `createdAt` / `updatedAt` | datetime | 时间戳 |

## 5. 装修小圈接口 `/api/posts`

> 所有接口需鉴权。

### 5.1 发帖

`POST /api/posts` （需鉴权）

**请求体**（JSON）：
```json
{
  "content": "分享我家现代简约完工效果～",
  "images": ["http://localhost:8080/files/uploads/a.png"]  // 可选，图片 URL 列表
}
```

**响应** `data`：`PostResponse`

### 5.2 帖子列表

`GET /api/posts?mine=false` （需鉴权）

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `mine` | bool | `false`（默认）全部帖子；`true` 仅当前用户帖子 |

**响应** `data`：`PostResponse[]`

### 5.3 删除帖子

`DELETE /api/posts/{id}` （需鉴权，仅作者可删）

**响应** `data`：`null`

### 5.4 点赞 / 取消点赞（切换）

`POST /api/posts/{id}/like` （需鉴权）

**响应** `data`：`LikeResult`
```json
{ "likeCount": 12, "liked": true }   // liked=true 表示当前用户已赞
```

### 5.5 评论

`POST /api/posts/{id}/comments` （需鉴权）

**请求体**（JSON）：
```json
{ "content": "好漂亮！求链接" }   // content 必填，非空
```

**响应** `data`：`CommentResponse`
```json
{
  "id": 5, "postId": 3, "userId": 1,
  "authorName": "张三", "authorAvatar": null,
  "content": "好漂亮！求链接", "createdAt": "2026-07-13T11:00:00"
}
```

### 5.6 删除评论

`DELETE /api/comments/{id}` （需鉴权，仅作者可删）

**响应** `data`：`null`

### 5.7 `PostResponse` / `CommentResponse` 字段

**PostResponse**：
```json
{
  "id": 3, "userId": 1, "authorName": "张三", "authorAvatar": null,
  "content": "分享完工效果",
  "images": ["http://.../a.png"],
  "likeCount": 12, "commentCount": 3,
  "likedByMe": true,
  "createdAt": "2026-07-13T11:00:00",
  "comments": [ "CommentResponse[]" ]
}
```

## 7. `sceneConfig` 结构说明

`GenerationResponse.sceneConfig` 为 JSON 字符串，前端按 `type` 选择渲染方式。

### 7.1 智谱真实出图：`photo-tour`

```json
{
  "type": "photo-tour",
  "styleLabel": "现代简约",
  "rooms": [
    {
      "id": 0,
      "name": "客厅",
      "connections": [1, 2, 3],
      "panoramaUrl": "http://localhost:8080/files/panoramas/xxx.jpg"
    },
    { "id": 1, "name": "主卧", "connections": [0], "panoramaUrl": "..." },
    { "id": 2, "name": "厨房", "connections": [0, 3], "panoramaUrl": "..." },
    { "id": 3, "name": "卫生间", "connections": [0, 2], "panoramaUrl": "..." }
  ]
}
```

- 前端以平面照片展示（按真实比例 `cover`），VR 式缓慢水平扫视；底部缩略图切换房间。
- 兼容旧标识 `panorama-tour`（前端同时识别）。

### 7.2 内置程序化生成：`procedural-apartment`

```json
{ "type": "procedural-apartment", "...": "（户型/家具等程序化数据，前端 Three.js 重建）" }
```

- 前端用 Three.js 依据 `sceneConfig` 重建可交互 3D 户型（自由旋转/缩放/平移、线框、自动旋转、光照调节、720° 球体内贴图）。
- 无 `panoramaUrl` / `modelUrl`，仅靠 `sceneConfig` 渲染。

## 9. 关键状态码 / 异常场景速查

| 场景 | HTTP / code | 处理建议 |
| --- | --- | --- |
| 未带 Token 访问受保护接口 | 401 | 重新登录 |
| 智谱 `429` 限流（短时） | 任务 `FAILED`，`errorMessage` 含"限流…重试" | 等待后重新点生成（后端已对 429/5xx 做指数退避重试） |
| 智谱额度耗尽（持续 429 / 402） | 任务 `FAILED`，`errorMessage` 含"额度不足/充值" | 到 open.bigmodel.cn 充值 |
| 智谱 `401/403` | 任务 `FAILED`，`errorMessage` 含"API Key 无效" | 检查 `app.ai.api-key` |
| 上传文件过大 | 400 "上传文件过大" | 压缩后重试 |
| 参数校验失败（如用户名过短） | 400 + 具体 message | 按提示修正入参 |
