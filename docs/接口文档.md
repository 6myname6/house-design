# 筑梦家 · 接口文档 V1.0

## 通用约定

> 接口基址：`/api`（开发环境由 Vite 代理到 `http://localhost:8080`）；静态图片直链 `/files/**`。
>
> 编码：请求与响应均为 `UTF-8`；JSON 接口 `Content-Type: application/json`。

### 鉴权

除登录、注册、发送验证码、验证码登录四个接口外，其余接口都需要在请求头携带 JWT：

```
Authorization: Bearer <token>
```

token 由登录接口返回，有效期 7 天。未携带 / 非法 / 过期 / 已登出的 token 返回 HTTP 401，响应体：

```json
{ "code": 401, "message": "登录已过期，请重新登录", "data": null }
```

### 统一响应结构

所有接口统一返回：

| 参数名 | 类型 | 是否必须 | 备注 |
| --- | --- | --- | --- |
| code | number | 必须 | 响应码，200 代表成功，其余代表失败 |
| message | string | 非必须 | 提示信息；失败时为可直接展示给用户的原因 |
| data | object / array / string / number / null | 非必须 | 返回的数据 |

- 业务成功与业务失败的 **HTTP 状态码都是 200**，以响应体 `code` 为准；只有鉴权失败返回 HTTP 401。
- 业务错误码：400 参数 / 业务错误，401 未登录或凭证无效，404 资源不存在或不属于当前用户，409 操作冲突，429 触发频率限制，500 服务器内部错误，503 依赖服务暂不可用。
- 失败响应统一为 `{ "code": 错误码, "message": "提示", "data": null }`，下文只给成功响应样例。

### 通用规则

- 分页参数：`pageNum`（从 1 开始，默认 1）、`pageSize`（默认 20，最大 50，越界自动收敛）；分页响应为 `{ total, records }`。
- 文件上传：`multipart/form-data`，仅接受 jpg / jpeg / png / gif / webp，单文件不超过 20MB。
- 时间字段：字符串，格式 `yyyy-MM-dd'T'HH:mm:ss`，如 `"2026-10-14T10:00:00"`。
- 业务接口中的图片一律传**已通过上传接口获得的本系统图片 URL**。

## 1. 认证管理

### 1.1 注册

#### 1.1.1 基本信息

> 请求路径：/api/auth/register
>
> 请求方式：POST
>
> 接口描述：新用户注册（手机号 + 验证码 + 用户名 + 密码），成功返回新用户 ID，之后需调用登录接口换取令牌；5 秒内禁止重复提交
>
> 是否鉴权：否

#### 1.1.2 请求参数

参数格式：application/json

参数说明：

| 参数名 | 类型 | 是否必须 | 备注 |
| --- | --- | --- | --- |
| username | string | 必须 | 用户名，3–32 字符 |
| phone | string | 必须 | 大陆手机号，正则 `^1[3-9]\d{9}$` |
| code | string | 必须 | 短信验证码（先调 1.3 获取） |
| password | string | 必须 | 密码，8–32 字符 |

请求参数样例：

```json
{
  "username": "zhangsan",
  "phone": "13800138000",
  "code": "483920",
  "password": "12345678"
}
```

#### 1.1.3 响应数据

参数格式：application/json

参数说明：

| 参数名 | 类型 | 是否必须 | 备注 |
| --- | --- | --- | --- |
| code | number | 必须 | 200 成功 |
| message | string | 非必须 | 提示信息 |
| data | number | 非必须 | 新用户 ID |

响应数据样例：

```json
{
  "code": 200,
  "message": "success",
  "data": 52
}
```

常见失败：400 验证码错误或已过期 / 用户名已被占用 / 手机号已注册；409 操作太频繁，请稍后再试。

### 3.1 创建项目

#### 3.1.1 基本信息

> 请求路径：/api/projects
>
> 请求方式：POST
>
> 接口描述：创建设计项目并上传设计图（户型图）
>
> 是否鉴权：是

#### 3.1.2 请求参数

参数格式：multipart/form-data

参数说明：

| 参数名 | 类型 | 是否必须 | 备注 |
| --- | --- | --- | --- |
| name | string | 必须 | 项目名称，最长 128 字符 |
| description | string | 非必须 | 项目描述，最长 512 字符 |
| style | string | 非必须 | 自定义风格要求（自由文本，最长 512） |

```
POST /api/projects
Content-Type: multipart/form-data; boundary=----boundary

------boundary
Content-Disposition: form-data; name="name"

我的三居室
------boundary
Content-Disposition: form-data; name="style"

原木色、温馨、多绿植
------boundary
Content-Disposition: form-data; name="styleLabel"

modern-minimalist
------boundary
Content-Disposition: form-data; name="designImage"; filename="floorplan.png"
Content-Type: image/png

<二进制文件内容>
------boundary--
```

| data | object | 非必须 | 新建的项目（Project 结构见 3.5） |

响应数据样例：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 10,
    "name": "我的三居室",
    "description": "朝阳 120㎡",
    "style": "原木色、温馨、多绿植",
    "styleLabel": "现代简约",
    "designImageUrl": "http://localhost:8080/files/designs/7c2a.png",
    "createdAt": "2026-10-14T10:00:00",
    "updatedAt": "2026-10-14T10:00:00"
  }
}
```

常见失败：400 请至少填写风格要求或选择风格标签 / 上传图片不能为空 / 不支持的装修风格标签。

> 是否鉴权：是

参数说明：

| 参数名 | 类型 | 是否必须 | 备注 |
| --- | --- | --- | --- |
| projectId | number | 必须 | 项目 ID |

请求参数样例：

```
/api/projects/10/generate
```

#### 4.1.3 响应数据

>

>

```
<二进制文件内容>
------boundary--
```

#### 6.1.3 响应数据

## 7. AI 设计助手

### 7.1 AI 对话

#### 7.1.1 基本信息

> 请求路径：/api/ai/chat
>
> 请求方式：POST
>
> 接口描述：与装修设计 AI 对话；纯文本支持多轮记忆，图文 / 纯图为单轮
>
> 是否鉴权：是

#### 7.1.2 请求参数

参数格式：application/json

参数说明：

| 参数名 | 类型 | 是否必须 | 备注 |
| --- | --- | --- | --- |
| question | string | 非必须 | 文本问题，最长 2000 字符；与 images 不可同时为空 |
| images | string[] | 非必须 | 图片 URL 列表（须为本系统上传所得地址），最多 4 张 |
| conversationId | string | 非必须 | 会话 ID，最长 64；首轮不传，非空时必须为标准 UUID，后续轮原样带回 |

请求参数样例：

纯文本首轮：

```json
{
  "question": "现代简约风格怎么搭配主色调？"
}
```

纯文本追问：

```json
{
  "question": "那预算 5 万怎么落地？",
  "conversationId": "9f2c1a7e-3b2d-4c8e-9a1f-0c2d4e6f8a01"
}
```

图文提问：

```json
{
  "question": "这张客厅效果图是什么风格？",
  "images": ["http://localhost:8080/files/uploads/a3f9c1e2.png"]
}
```

#### 7.1.3 响应数据

参数格式：application/json

纯文本链路：`data` 为对象。

参数说明：

| 参数名 | 类型 | 是否必须 | 备注 |
| --- | --- | --- | --- |
| code | number | 必须 | 200 成功 |
| message | string | 非必须 | 提示信息 |
| data | object | 非必须 | 纯文本链路返回对象 |
| \|- conversationId | string | 必须 | 会话 ID（首轮由后端生成，后续原样返回） |
| \|- answer | string | 必须 | AI 回答（Markdown 文本） |

响应数据样例（纯文本）：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "conversationId": "9f2c1a7e-3b2d-4c8e-9a1f-0c2d4e6f8a01",
    "answer": "现代简约风格通常以中性色为主……"
  }
}
```

图文 / 纯图链路：`data` 直接为回答字符串（不走多轮记忆）；纯图时后端按「请解释这张图」处理。

响应数据样例（图文）：

```json
{
  "code": 200,
  "message": "success",
  "data": "这是现代简约风格，特点是线条干净、配色克制……"
}
```

常见失败：400 输入不能为空 / 非法会话标识 / 仅允许使用已上传的图片地址 / 仅支持 jpg/png/gif/webp 格式图片；503 对不起，当前AI服务繁忙，请稍后再试~。

## 附录 A：sceneConfig 数据结构

`Generation.sceneConfig` 是一个 **JSON 字符串**，解析后描述照片漫游场景，当前为 `photo-tour` v2；缺失或无 rooms 时前端按单图模式降级，使用 `Generation.panoramaUrl`。

数据样例：

```json
{
  "type": "photo-tour",
  "version": 2,
  "styleLabel": "现代简约",
  "floorPlanImageUrl": "http://localhost:8080/files/designs/xxx.jpg",
  "entryRoomId": "living",
  "rooms": [
    {
      "id": "living",
      "name": "客厅",
      "approxArea": "约18㎡",
      "imageUrl": "http://localhost:8080/files/panoramas/uuid1.jpg",
      "bbox": { "x": 0.12, "y": 0.3, "w": 0.36, "h": 0.42 },
      "hotspots": [
        { "targetRoomId": "kitchen", "label": "厨房", "x": 0.76, "y": 0.66 }
      ]
    }
  ]
}
```

顶层字段：

| 参数名 | 类型 | 是否必须 | 备注 |
| --- | --- | --- | --- |
| type | string | 必须 | 场景类型，当前为 `photo-tour` |
| version | number | 必须 | 结构版本，当前为 2 |
| styleLabel | string | 非必须 | 风格中文名 |
| floorPlanImageUrl | string | 非必须 | 用户原始户型图 URL，小地图底图 |
| entryRoomId | string | 必须 | 首屏房间 ID，必须存在于 rooms |
| rooms | object[] | 必须 | 房间列表 |

Room：

| 参数名 | 类型 | 是否必须 | 备注 |
| --- | --- | --- | --- |
| id | string | 必须 | 房间标识，同套唯一 |
| name | string | 必须 | 房间中文名 |
| approxArea | string | 非必须 | AI 估算面积文案（如「约18㎡」），仅供展示 |
| imageUrl | string | 必须 | 该房间写实宽幅效果图 URL |
| bbox | object | 非必须 | 房间在户型图上的归一化位置，可能为 null |
| hotspots | object[] | 非必须 | 通往相邻房间的热点 |

BBox（原点为户型图左上角，取值 0–1）：`x` / `y` 左上角坐标，`w` / `h` 宽高。

Hotspot（坐标原点为当前房间画面左上角，取值 0–1）：

| 参数名 | 类型 | 是否必须 | 备注 |
| --- | --- | --- | --- |
| targetRoomId | string | 必须 | 目标房间 ID，必须存在于同套 rooms |
| label | string | 必须 | 热点旁展示的目标房间名 |
| x | number | 必须 | 水平位置 |
| y | number | 必须 | 垂直位置 |
