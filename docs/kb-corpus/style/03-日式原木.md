# 日式原木风（Japanese Natural）

## 一句话定位

以原木和留白构成低对比度的安静空间，靠材质本身的质感而不是装饰取胜。

## 色彩

原木色、米白、浅灰构成三段式，颜色之间明度差很小，整体偏"糊"。
避免使用纯白与纯黑——日式讲究柔和过渡，高对比会破坏安静感。

## 材质

- 木作：橡木、白蜡木为主，木色统一不超过两种
- 墙面：硅藻泥或哑光乳胶漆，可做局部肌理
- 隔断：木格栅、障子纸、长虹玻璃
- 布艺：亚麻、粗棉，允许有自然褶皱
- 地面：木地板通铺，或客餐厅用哑光仿古砖

## 适合的户型与人群

适合层高 2.7m 以上、采光良好的户型，最好有阳台或飘窗。
适合有幼儿的家庭（无尖锐造型、地面柔和）。
不适合南方潮湿的一楼——大量木作在湿度高的环境下容易变形、发霉。

## 常见翻车点

1. **木色超过三种**：橡木、胡桃木、樱桃木混用，颜色打起来就变成"杂木风"。
2. **格栅做太密**：擦灰成本极高，三个月后积灰明显。
3. **留白变空白**：日式靠"少而精"，家具数量少但每件都要有质感，便宜家具会立刻露馅。
4. **忽略湿度**：南方地区需配套除湿，木作含水率要控制在 12% 以内。

## 造价参考

中档标准下约 1700–2500 元/㎡。木作占比高，人工费比北欧风高约 15%。
