# 现代简约风格（Modern Minimal）

## 一句话定位

用克制的线条和隐藏式的收纳换取整洁感，本质是"把复杂藏在看不见的地方"。

## 色彩

黑、白、灰三色构成主基调，允许出现一个高纯度强调色（橙、深绿、暗红），占比不超过 5%。
墙面通常为浅灰或米白，顶面纯白，踢脚线与墙同色以弱化边界。

## 材质

- 台面与墙面：岩板、石英石、微水泥
- 柜体：哑光烤漆或双饰面，面板不做造型线
- 金属：黑色或枪灰色细边框，用于玻璃隔断、灯具
- 灯光：以无主灯设计为主，靠筒灯、线性灯、洗墙灯分层布光

## 适合的户型与人群

适合 100㎡ 以上的大平层、户型方正的空间。
适合收纳需求高、愿意维持整洁的家庭，以及在家办公人群。
不适合杂物多、没有收纳习惯的家庭——简约风格的容错率极低。

## 常见翻车点

1. **极简做成简陋**：只做了白墙和便宜家具，没有材质对比，看着像没装修。
2. **收纳容量估算不足**：柜体一少，入住三个月就回到杂乱状态，风格彻底崩掉。
3. **岩板上墙过多**：大面积岩板配反光，容易做出酒店大堂感，失去居住感。
4. **无主灯做失败**：只装筒灯不做照度计算，会出现"地上亮、墙上暗"的斑驳感。

## 造价参考

中档标准下约 1800–2800 元/㎡。无主灯、岩板、隐形门是三个主要加价项，单项可增加总价 8%–15%。
