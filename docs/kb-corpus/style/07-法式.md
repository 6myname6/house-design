# 法式风格（French）

## 一句话定位

靠线条和比例制造优雅感，核心是墙面分格、石膏线和对称构图，而不是繁复装饰。

## 色彩

以奶白、象牙白、浅灰为底，点缀雾霾蓝、灰粉、复古绿。
墙面通常为"墙浅顶白"，踢脚线和门套用同色系加深一档。

## 材质

- 墙面：石膏线分格、护墙板、法式雕花线条
- 地面：人字拼或鱼骨拼木地板，或浅色石纹砖
- 五金：黄铜、做旧金
- 软装：丝绒、提花、水晶灯具
- 家具：带弧线的腿型、雕花边框

## 适合的户型与人群

适合 100㎡ 以上、层高 2.8m 以上的户型，线条造型需要空间呼吸。
适合追求精致感、接受较高清洁成本的用户。
不适合小户型——护墙板和石膏线在小空间里会显得拥挤。

## 常见翻车点

1. **石膏线比例失控**：线条过粗或分格过多，会变成"欧式会所"。
2. **层高不够强行做**：护墙板 + 吊顶会吃掉 10–15cm 净高。
3. **黄铜过多**：全屋金色五金会显得俗气，建议集中在 2–3 处。
4. **家具风格混搭**：法式线条配现代板式家具，比例完全对不上。

## 造价参考

中档标准下约 2200–3200 元/㎡。石膏线与护墙板的人工费占比高，人字拼地板另加 15%–25%。
