# 轻奢风格（Light Luxury）

## 一句话定位

用少量高价值材料（石材、金属、皮革）在克制的前提下提升质感，是"花钱花在看得见的地方"。

## 色彩

以中性灰、米白为主，搭配香槟金、古铜、墨绿或深蓝作点缀。
整体保持低彩度，靠金属于石材的光泽制造层次，而不是靠颜色。

## 材质

- 墙面：局部岩板、硬包、护墙板
- 台面：天然大理石或岩板
- 金属：香槟金、古铜，用于线条、灯具、五金
- 软装：真皮、丝绒、金属边框家具
- 地面：大板瓷砖通铺，缝隙控制到 1.5mm 以内

## 适合的户型与人群

适合 100㎡ 以上的改善型住宅。
适合预算相对充足、追求质感的用户，以及作为婚房或改善房使用。
不适合预算紧张的情况——轻奢的质感高度依赖材料真实档次，降档就变成"廉价奢华"。

## 常见翻车点

1. **材料降档**：用仿大理石纹瓷砖替代天然石材，远看像、近看差，整体掉档。
2. **金色泛滥**：金色元素超过 3 处就失去"轻"的感觉。
3. **灯光做太满**：大量灯带 + 射灯会变成酒店大堂。
4. **忽视细节工艺**：缝隙、收口、踢脚线处理不到位，轻奢的"精"就没了。

## 造价参考

中档标准下约 2500–3800 元/㎡。天然石材、金属线条、硬包为主要加价项，高档可超过 5000 元/㎡。
