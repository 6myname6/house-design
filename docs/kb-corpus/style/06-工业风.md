# 工业风（Industrial）

## 一句话定位

保留结构的原始感，用裸露材质和金属构件制造粗粝气质，是 loft 和复式空间的原生风格。

## 色彩

以水泥灰、铁黑、锈色为主，整体明度低。
可用暖色皮革（棕、酒红）或铜色作唯一的"温度来源"。
墙面很少做纯暖色，一旦出现米黄就会与裸露质感冲突。

## 材质

- 墙面：清水混凝土、微水泥、灰色肌理涂料
- 结构：裸露管道、外露砖墙、钢架
- 金属：黑铁、拉丝不锈钢，用于灯具、置物架、桌腿
- 家具：皮质沙发、实木厚板桌、金属框架
- 地面：大规格仿古砖、水泥自流平

## 适合的户型与人群

适合 loft、复式、大开间，层高建议 3m 以上。
适合单身或二人居住、接受粗粝质感的用户。
不适合小户型和有老人小孩的家庭——硬质材料多、磕碰风险高、容易显冷。

## 常见翻车点

1. **"假工业"**：贴假砖、做假管道，成本不低但一眼假。
2. **忽略保温与隔音**：裸露墙体隔音差，管道噪音明显。
3. **全屋深色显压抑**：深色占比过高时室内照度不足，需要加装轨道灯补光。
4. **灰尘问题**：裸露砖墙与粗糙肌理容易积灰，清洁成本高。

## 造价参考

中档标准下约 1700–2600 元/㎡。若做真裸墙或清水混凝土，单价上浮 20%–30%。
