# 新中式风格（New Chinese）

## 一句话定位

把中式符号做减法、把木作做轻，用现代工艺承载东方气质，而不是堆砌传统家具。

## 色彩

以深木色（胡桃木、黑檀）+ 米白 + 水墨灰为主。
允许一处中国红或黛蓝作点缀，占比不超过 3%。
墙面很少用纯白，多用米白、宣纸色，避免冷白破坏温润感。

## 材质

- 木作：胡桃木、黑胡桃饰面，木纹要顺直不夸张
- 墙面：局部硬包、护墙板或山水纹石材
- 隔断：木格栅、月洞门、镂空屏风
- 地面：深色木地板或哑光灰色地砖
- 装饰：留白挂画、陶器、绿植（松、竹）

## 适合的户型与人群

适合 110㎡ 以上、户型方正的改善型住宅。
适合中年家庭、有品茶或收藏习惯的用户。
不适合小户型——深木色会明显压缩空间感。

## 常见翻车点

1. **符号堆砌**：屏风 + 格栅 + 回字纹 + 中式家具一起上，变成"仿古餐厅"。
2. **木色过深导致压抑**：深色木作面积超过墙面的 30%，房间会明显变暗。
3. **现代与中式不融合**：现代沙发配中式茶几，比例和线条对不上。
4. **忽略灯光**：深色木作需要更亮的照度，常规布光会显得沉闷。

## 造价参考

中档标准下约 2200–3500 元/㎡。护墙板、硬包、木格栅为主要加价项，高档可超过 4000 元/㎡。
