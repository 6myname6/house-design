# 北欧风格（Scandinavian）

## 一句话定位

以浅色打底、木材取暖，追求"亮、简、不冷"的居住感，是小户型和采光不足房型的第一选择。

## 色彩

墙面以纯白（NCS S0500-N 附近）或极浅灰为主，全屋不超过两个基础色。
点缀色控制在低饱和区间：雾霾蓝、鼠尾草绿、燕麦色、浅赭。
地面与家具的木色是唯一的"暖色来源"，木色一旦偏红就会破坏整体调性。

## 材质

- 地面：浅色橡木或白蜡木，纹理直、节疤少；预算紧可用浅色强化复合地板
- 墙面：哑光乳胶漆，不做复杂造型
- 家具：细腿、浅木色、布艺沙发以棉麻为主
- 布艺：浅灰、米白，避免光泽感面料

## 适合的户型与人群

最适合 60–90㎡ 的小三房、南北通透但单面采光的户型。
适合年轻首套、有幼儿的家庭（浅色耐看、翻新成本低）。
不适合层高低于 2.6m 且窗户很小的房间——浅色在没有光的房间里会发灰，显得脏。

## 常见翻车点

1. **全屋浅色导致"空冷"**：缺少木质和织物，看起来像样板间。至少在一面墙或一件家具上用深色压住。
2. **木纹假**：低价强化地板的印刷纹理重复率高，一眼假。
3. **灯光不足**：只装一盏主灯，浅色墙面会把影子照得更硬。建议主灯 + 两处间接光。
4. **点缀色过多**：超过两种彩色就变成"杂货铺"。

## 造价参考

中档标准下约 1500–2200 元/㎡（含柜体、不含家电），低于 1200 元/㎡ 时木作与布艺质感会明显掉档。
