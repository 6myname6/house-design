# 侘寂风（Wabi-Sabi）

## 一句话定位

刻意保留不完美与时间痕迹，用粗糙肌理和低饱和色制造"安静而有缺陷"的美感。

## 色彩

大地色系为主：灰褐、陶土、石灰、旧木色。
整体明度中等、饱和度极低，几乎不使用纯色点缀。
色差靠材质的肌理变化制造，而不是靠颜色种类。

## 材质

- 墙面：微水泥、夯土肌理、艺术涂料，允许有手工痕迹
- 家具：原木厚板、藤编、陶器、粗陶灯具
- 布艺：亚麻、粗麻，允许有褶皱和不均匀
- 地面：微水泥或哑光仿石砖
- 装饰：干枝、手工陶罐、无框画

## 适合的户型与人群

适合采光好、有独立空间的户型，最好有庭院或大面积落地窗。
适合审美取向明确、接受"不完美"的用户。
不适合追求整洁明亮感的家庭，也不适合潮湿地区（微水泥易返潮）。

## 常见翻车点

1. **"穷装"被当成侘寂**：肌理材料本身不便宜，用便宜替代品会显得破旧。
2. **微水泥施工失败**：对基层和工艺要求高，开裂返工成本极高。
3. **光线不足显脏**：低明度 + 粗糙肌理，光线不够时整体发灰。
4. **软装不统一**：混入现代亮面材质会立刻破坏调性。

## 造价参考

中档标准下约 2000–3000 元/㎡。微水泥是主要成本项，单价通常 300–600 元/㎡。
