# 奶油风（Cream）

## 一句话定位

用低饱和的暖色调和圆弧造型制造柔软感，是近年小户型和精装房改造中最容易落地的风格。

## 色彩

奶白、燕麦、浅咖、杏色为主，整体明度高于日式、饱和度低于北欧。
所有颜色都带一点黄调，但**黄调不能过量**，否则会显得旧、显得脏。
点缀色推荐同一色系加深一档（焦糖、摩卡），靠深浅制造层次。

## 材质

- 墙面：艺术涂料、微水泥或哑光乳胶漆，肌理细腻
- 造型：圆弧门洞、圆弧包边、无棱角柜体
- 软装：羊羔绒、粗针织、短绒地毯
- 五金：哑光金或香槟金，亮面金会显廉价

## 适合的户型与人群

适合 60–90㎡ 的小户型、精装房改造（改动量小、工期短）。
适合女性和有幼儿的家庭，圆弧造型可减少磕碰。
不适合层高低于 2.5m 的空间——圆弧包边会进一步压低净高。

## 常见翻车点

1. **圆弧滥用**：门洞、柜门、吊顶全部做圆角，反而显得甜腻廉价。建议控制在 1–2 处作视觉重点。
2. **奶油色选偏黄**：刷完像旧墙，务必先做 1㎡ 色板实地试色。
3. **软装颜色不统一**：米白、象牙白、珍珠白混用，在暖光下会呈现脏灰色。
4. **只用暖光**：奶油风依赖光线，全屋 3000K 会显得闷，建议 3500–4000K 混合。

## 造价参考

中档标准下约 1600–2400 元/㎡。艺术涂料与圆弧木作是两个主要加价项。
