---

## 1. 产品概述

### 1.1 背景与目标
面向装修业主与设计师，提供"上传房屋设计图 → AI 生成可交互 3D 施工效果 → 社区分享交流"的一站式可视化平台。核心目标是让用户在施工前就能身临其境地预览装修完成效果，降低决策与沟通成本。

### 1.2 价值主张
- 零门槛出图：上传一张图即可生成写实效果图。
- 可交互漫游：3D 场景支持旋转/缩放/平移/自动环视。
- 风格可换：内置 5 种主流装修风格。
- 服务可插拔：内置 mock 免费生成，也可接入智谱真实文生图。
- 社区互动：装修灵感沉淀与分享。

### 1.3 技术栈
Spring Boot 3 + MySQL 8 + Vue 3 + Three.js + 智谱 CogView；本地文件系统存储。

| 角色 | 说明 | 权限 |

| 普通用户 | 业主 / 设计师 | 仅能访问与操作**自己**的项目、生成任务、帖子、点赞、评论（后端基于 userId 归属校验） |

## 4. 非功能需求（N）

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| N-1 | 分页 | 项目/帖子/生成记录列表必须分页，避免全量返回 |
| N-2 | 搜索筛选 | 社区帖子、历史项目支持按条件检索 |
| N-3 | 存储可扩展 | 支持对象存储（OSS/COS/S3）+ CDN |
| N-4 | 性能 | 生成任务异步化，不阻塞主请求；列表接口响应 < 500ms |
| N-5 | 可用性 | 单用户核心闭环（上传→生成→查看→分享）成功率 ≥ 99% |
| N-6 | 兼容性 | 现代浏览器（Chrome/Edge/Safari 近两版本）；移动端基本可用 |
| N-7 | 可观测 | 关键操作日志、生成失败原因可追溯 |

| 编号 | 需求 | 优先级 | 状态 | 说明 |

## 6. 关键业务流程

### 6.1 核心闭环
```
注册/登录 → 新建项目(传图+选风格) → 发起生成(异步) → 轮询状态
→ 查看 3D 效果 → (可选)社区发帖/浏览/点赞/评论
```

### 6.2 生成状态机
```
PENDING ──► PROCESSING ──► SUCCESS
                  │
                  └──────► FAILED (errorMessage 记录原因)
```
失败原因需覆盖：智谱 429 限流（指数退避重试）、额度不足、Key 无效、无 Key 回退等。

## 7. 验收标准（本期交付基线）

1. 单用户可完整走通"上传→生成→查看→分享"闭环。
2. 未登录访问受保护接口返回 401，前端自动登出。
3. 用户仅能访问自己的资源，越权返回 403/404。
4. 上传文件被类型与大小校验拦截非法文件。
5. 列表接口支持分页且不随数据量线性劣化。
6. 密钥不落库、不进版本库（已通过环境变量 + .gitignore 约束）。

## 9. 已知约束
- 照片模式为写实单张照片模拟，非真 360° 全景。
- 房间布局固定 4 间，暂不支持自定义户型。
- 社区评论扁平结构，暂不支持楼中楼。
- 本地文件系统存储，未接入对象存储/CDN。
