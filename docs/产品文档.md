# 筑梦家 · 产品文档

> 上传房屋设计图，由 AI 生成可交互的**3D 施工效果**（独立的三维动态网页）。
> 技术栈：**Spring Boot 3 + MySQL 8 + Vue 3 + Three.js + 智谱 CogView 文生图**。

---

## 1. 产品定位

「筑梦家」是一个面向装修业主 / 设计师的房屋装修效果可视化平台。用户上传户型平面图或设计图，平台调用 AI 生成对应装修风格的**写实效果图**与**可交互的 3D 漫游场景**，让用户在"施工前"就能身临其境地看到装修完成后的样子，并能在社区分享交流。

产品核心价值：

- **零门槛出图**：无需建模软件，上传一张图即可生成多房间写实效果图。
- **可交互漫游**：3D 场景支持旋转、缩放、平移、自动环视；照片模式支持 VR 式缓慢扫视。
- **风格可换**：内置 5 种主流装修风格，一键切换不同色调与软装氛围。
- **生成直连智谱**：后端直接调用智谱 CogView 文生图生成写实效果图（无内置 mock、无多 provider 抽象）。
- **社区互动**：「装修小圈」发帖、点赞、评论，沉淀装修灵感。

## 2. 核心功能

| 模块 | 功能 | 说明 |
| --- | --- | --- |
| 账号 | 注册 / 登录 / 个人信息 | JWT 鉴权，密码 BCrypt 加密；支持修改昵称与头像 |
| 项目 | 创建 / 列表 / 详情 / 删除 | 一个项目 = 一份设计图 + 风格要求；上传图可为户型图 / CAD 导出 / 手绘稿；风格支持「预设标签 + 自由描述」双输入 |
| 风格 | 内置 5 种装修风格 | `GET /api/styles` 提供列表（code + 中文名），`DesignStyle` 枚举为单一数据源 |
| 生成 | 一键生成 3D 效果 | 异步任务；支持状态轮询；**后端已实现**（直连智谱，见 §4.1） |
| 3D 查看 | 漫游 / 旋转 / 缩放 / 平移 / 自动扫视 | **前端规划中，暂未实现**（`Viewer3D.vue`） |
| 社区 | 发帖 / 列表 / 我的帖子 / 删除 / 评论点赞 / 楼中楼回复 | 帖子图文发布（分页列表）；评论支持两级楼中楼（`parent_id`）；图片可上传至平台后引用 URL |
| 文件 | 通用上传 | 头像、帖子图片等统一走 `/api/files/upload`，扩展名白名单 + UUID 重命名 |

## 3. 用户角色

当前版本为**单角色**（普通用户），所有登录用户权限一致：

- 仅可访问/操作**自己**的项目、生成任务、帖子与点赞（后端基于 `userId` 做归属校验）。
- 鉴权失败（401）时前端自动登出并跳转登录页。

## 4. 典型使用流程

```
注册 / 登录
   │
   ▼
首页 / 项目列表 ──► 新建项目（填名称、选风格、上传设计图）
   │
   ▼
项目详情 ──► 点击「生成 3D 施工效果」
   │            （后端创建 PENDING 任务 → 异步处理 → 轮询状态）
   ▼
生成中（轮询 PENDING → PROCESSING → SUCCESS）
   │
   ▼
查看 3D 效果（多房间写实照片 + VR 式扫视）
   │
   ▼
（可选）到「装修小圈」分享效果图、浏览他人帖子、点赞评论
```

### 4.1 生成模式说明

**方案定稿：不用 mock，直接调智谱 CogView 文生图**（后端 `ZhipuImageService`；不设 ImageTo3DService 抽象 / 工厂）：

```
发起（POST /images/generations，需 ZHIPU_API_KEY）
  → 轮询（GET /async-result/{task_id}）
  → 拿临时图片 URL → 下载落盘 ./storage/designs/（本地持久化）
  → 写入 panoramaUrl + sceneConfig（type=photo-tour）
```

产物：单张写实效果图（落库为本地可访问 URL）。`sceneConfig` 记录 `photo-tour` 渲染方式。

> 未配置 `ZHIPU_API_KEY` 时生成任务直接 FAILED（`errorMessage` 提示配置 Key），**不做 mock 兜底**。

## 6. 技术架构

### 6.1 整体架构

```
┌─────────────┐      HTTP / JSON       ┌──────────────────────────┐
│  Vue 3 SPA   │  ───────────────────►  │   Spring Boot 3 后端       │
│ (Vite:5173)  │  ◄───────────────────  │   (Tomcat:8080)           │
└─────────────┘      /api, /files        └────────────┬─────────────┘
                                                      │
                                          ┌───────────┼────────────┐
                                          ▼           ▼            ▼
                                      MySQL 8    本地存储(storage)  智谱 CogView API
                                                  (设计图/全景图)    (文生图)
```

- **前端**：Vue 3 + Vite + Pinia + Vue Router + Element Plus + Three.js；Axios 封装（`baseURL=/api`，Vite 代理转发到 `:8080`）。
- **后端**：Spring Boot 3 + MyBatis-Plus（`BaseMapper` + LambdaQueryWrapper + 分页插件）+ WebFlux `WebClient`（调智谱 CogView）；JWT 拦截器 + ThreadLocal 用户上下文；静态资源 `/files/**` 映射至 `storage/` 目录。
- **存储**：MySQL 存结构化数据；本地文件系统存上传图与生成图（默认 `./storage`，可通过 `app.storage.location` 配置）。

### 6.2 关键包结构

```
backend/src/main/java/com/housedesign/
├── config/      # WebConfig、MybatisPlusConfig、OpenApiConfig、AsyncConfig（生成线程池）
├── common/      # Result（统一响应）、BusinessException、GlobalExceptionHandler、UserContext
├── controller/  # Login / Personal / Project / Generation / Post / Comment / Style / File
├── dto/         # request / response（含 PageResult 分页通用响应）
├── entity/      # User / DesignProject / GeneratedModel / Post* / CommentLike / DesignStyle / GenerationStatus
├── interceptor/ # JwtInterceptor
├── mapper/      # BaseMapper 接口（User / Project / GeneratedModel / Post / PostComment / PostLike / CommentLike）
├── service/     # 业务接口 + impl（含 ZhipuImageService 智谱直连）
└── util/        # JwtUtil 等工具
```

### 6.3 生成状态机（`GenerationStatus`）

```
PENDING ──► PROCESSING ──► SUCCESS
                  │
                  └──────► FAILED（errorMessage 记录原因）
```

- `PENDING`：任务已创建，等待异步处理。
- `PROCESSING`：异步线程池中正在生成（调智谱 AI 出图）。
- `SUCCESS`：生成完成，`panoramaUrl` / `sceneConfig` 等字段已填充。
- `FAILED`：失败，`errorMessage` 含原因（如智谱 429 限流/额度不足、Key 无效等）。

| 项 | 要求 |
| --- | --- |
| JDK | 17+ |
| Maven | 3.8+ |
| MySQL | 8.x（运行） |
| Node.js | 18+ |

启动顺序：数据库（自动建库 `house_design`）→ 后端 `mvn spring-boot:run`（:8080）→ 前端 `npm install && npm run dev`（:5173）。详见仓库根 `README.md`。

### 8.1 配置智谱 Key（生成功能必需）

生成功能直连智谱，需配置 API Key（环境变量 `ZHIPU_API_KEY`，见 yml 占位符）：

```yaml
# backend/src/main/resources/application.yml
app:
  ai:
    api-key: ${ZHIPU_API_KEY}   # 未配置时生成任务 FAILED
    base-url: "https://open.bigmodel.cn/api/paas/v4"
    image-model: cogview-4
```

## 9. 已知约束与后续规划

- **生成与 3D 查看**：生成后端已实现（直连智谱）；3D 查看前端 `Viewer3D.vue` 为规划中模块（接口文档 §4/§7 已定义契约），待开发。
- **照片模式为写实照片而非真 360° 全景**：文生图本质是单张透视照片，无法像球面那样真实转动；VR 扫视为 CSS 模拟的转头视差（轻微裁切边缘）。
- **房间布局固定**：当前默认生成「客厅/主卧/厨房/卫生间」4 个房间，暂不支持自定义户型。
- **评论支持两级楼中楼**：`parent_id` 实现"评论→回复"，暂不支持更深层级嵌套。
- 若需真 720° 实景漫游，需接入专门产出等距柱状全景图的 360 全景服务。
