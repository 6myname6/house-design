# 筑梦家 · 产品文档

> 上传房屋设计图，由 AI 生成可交互的**3D 施工效果**（独立的三维动态网页）。
> 技术栈：**Spring Boot 3 + MySQL 8 + Vue 3 + Three.js + 阿里云百炼 wanx2.1-t2i-turbo 文生图**；登录限流使用 Redis（已实现，见需求文档 S-3），邮箱验证码登录基于 Redis（已实现，见需求文档 A-11），退出登录的 token 黑名单也基于 Redis（已实现 2026-10-07，见需求文档 A-9 / S-4），AI 多模态对话使用 LangChain4j + 百炼 qwen3-vl-plus（已上线，见需求文档 §10.4）。

---

## 1. 产品定位

「筑梦家」是一个面向装修业主 / 设计师的房屋装修效果可视化平台。用户上传户型平面图或设计图，平台调用 AI 生成对应装修风格的**写实效果图**与**可交互的 3D 漫游场景**，让用户在"施工前"就能身临其境地看到装修完成后的样子，并能在社区分享交流。

产品核心价值：

- **零门槛出图**：无需建模软件，上传一张图即可生成多房间写实效果图。
- **可交互漫游**：3D 场景支持旋转、缩放、平移、自动环视；照片模式支持 VR 式缓慢扫视。
- **风格可换**：内置 5 种主流装修风格，一键切换不同色调与软装氛围。
- **生成直连厂商 API**：后端直接调用阿里云百炼万相文生图生成写实效果图（无内置 mock、无多 provider 抽象）。
- **社区互动**：「装修小圈」发帖、点赞、评论，沉淀装修灵感。

## 3. 用户角色

当前版本为**单角色**（普通用户），所有登录用户权限一致：

- 仅可访问/操作**自己**的项目、生成任务、帖子与点赞（后端基于 `userId` 做归属校验）。
- 鉴权失败（401）时前端自动登出并跳转登录页。

### 4.1 生成模式说明

**方案定稿：不用 mock，直接调阿里云百炼万相 wanx2.1-t2i-turbo 文生图**（后端 `AIimageService`；不设 ImageTo3DService 抽象 / 工厂）：

```
发起（POST {host}/api/v1/services/aigc/text2image/image-synthesis，X-DashScope-Async: enable，需 BAILIAN_API_KEY）
  → 轮询（GET {host}/api/v1/tasks/{task_id}，直至 SUCCEEDED）
  → 拿临时图片 URL（24h 有效）→ 转存阿里云 OSS（外部图片下载字节上限 20MB）
  → 写入 panoramaUrl + sceneConfig（type=photo-tour）
```

产物：单张写实效果图（转存 OSS 后落库为可访问 URL）。`sceneConfig` 记录 `photo-tour` 渲染方式。

> 未配置 `BAILIAN_API_KEY` 时生成任务直接 FAILED（`errorMessage` 提示配置 Key），**不做 mock 兜底**。

## 6. 技术架构

### 6.1 整体架构

```
┌─────────────┐      HTTP / JSON       ┌──────────────────────────┐
│  Vue 3 SPA   │  ───────────────────►  │   Spring Boot 3 后端       │
│ (Vite:5173)  │  ◄───────────────────  │   (Tomcat:8080)           │
└─────────────┘   /api ＋OSS公网URL直出  └────────────┬─────────────┘
                                                      │
                              ┌───────────────┬───────┼───────────────┐
                              ▼               ▼       ▼               ▼
                          MySQL 8        Redis 7   阿里云 OSS       阿里云百炼
                          (业务数据)  (登录限流/短信验证码/登出黑名单) (设计图/全景图)  wanx2.1-t2i-turbo 文生图
                                                                     qwen3-vl-plus 多模态对话
```

- **前端**：Vue 3 + Vite + Pinia + Vue Router + Element Plus + Three.js；Axios 封装（`baseURL=/api`，Vite 代理转发到 `:8080`）；图片直接使用后端返回的 OSS 公网 URL。
- **后端**：Spring Boot 3 + MyBatis-Plus（`BaseMapper` + LambdaQueryWrapper + 分页插件）+ WebFlux `WebClient`（调百炼 DashScope 文生图）+ LangChain4j OpenAI 兼容模式（调 qwen3-vl-plus 多模态对话）；JWT 拦截器 + ThreadLocal 用户上下文。
- **存储**：MySQL 存结构化数据；上传图与生成图**唯一持久化到阿里云 OSS**（公共读 bucket，密钥经环境变量注入，缺失则启动 fail-fast；无本地磁盘回退）。
- **缓存**：Redis 只存认证相关短时数据，不存业务数据：① 登录失败计数 `login:fail:{username}`（TTL 10 分钟，登录限流已上线，见接口文档 §2.2）；② 邮箱验证码 `email:code:login:{email}`（TTL 5 分钟）与发送频控 `email:limit:login:{email}`（TTL 60 秒，均已上线，见接口文档 §1.6/§1.7）；③ 登出 token 黑名单 `jwt:blacklist:{SHA-256(token)}`（TTL = token 剩余有效期，最长 7 天，已实现 2026-10-07，见接口文档 §2.5）。

### 6.3 生成状态机（`GenerationStatus`）

```
PENDING ──► PROCESSING ──► SUCCESS
                  │
                  └──────► FAILED（errorMessage 记录原因）
```

- `PENDING`：任务已创建，等待异步处理。
- `PROCESSING`：异步线程池中正在生成（调百炼 AI 出图）。
- `SUCCESS`：生成完成，`panoramaUrl` / `sceneConfig` 等字段已填充。
- `FAILED`：失败，`errorMessage` 含原因（如上游 429 限流/额度不足、Key 无效等）。

## 9. 已知约束与后续规划

- **生成与 3D 查看**：均已上线——厂商直连生成（异步 + 轮询 + 409 防并发）与 `Viewer3D.vue` 全屏照片漫游（2026-10 实测通过）。
- **照片模式为写实照片而非真 360° 全景**：文生图本质是单张透视照片，无法像球面那样真实转动；VR 扫视为 CSS 模拟的转头视差（轻微裁切边缘）。
- **房间布局由 AI 识别**：视觉模型读户型图得出房间清单与拓扑（上限 6 个主要空间），查看页展示户型小地图与当前位置；精确 3D 几何重建（V-4 C 层）为后续方向。
- **评论支持两级楼中楼**：`parent_id` 实现"评论→回复"，暂不支持更深层级嵌套。
- 若需真 360° 实景漫游，需接入专门产出等距柱状全景图的 360 全景服务。
